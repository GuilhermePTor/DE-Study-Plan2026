E-Commerce Analytics Engine Pipeline

📊 Real Data Suggestions

Instead of mock data, use one of these enterprise-grade open datasets to build your platform:

  • Olist Brazilian E-Commerce Dataset (Kaggle) - Highly Recommended: Perfect fit for this schema. Contains 100k real orders from 2016-2018. Includes separate CSVs for Customers, Orders, Order Items, Products, and Reviews.
  • Instacart Market Basket Analysis (Kaggle): Massive dataset with 3 million grocery orders. Excellent for testing query performance, indexing, and window functions on a larger scale.
  • UK Retail Dataset (UCI Machine Learning Repo): 500k rows of real transactional data. Great for time-series analysis, calculating MRR, and building date spines.
  • Frankfurter API (External Data): For the Python pipeline in Week 4, use api.frankfurter.app. It's a free, open-source API for current and historical foreign exchange rates published by the European Central Bank.
