Course reference
SQLBolt
sqlbolt.com
Short interactive lessons. Best for solidifying SQL fundamentals with hands-on exercises.
Phase 1
DataLemur SQL Tutorial
datalemur.com/sql-tutorial
Best free resource for advanced SQL: window functions, CTEs, LEAD/LAG, pivoting, real business datasets.
Phase 1
pgexercises.com
pgexercises.com
PostgreSQL-specific drills. Use for daily practice. Postgres is the most common DE database.
Phase 1
Khan Academy — Intro to SQL
khanacademy.org
Video + interactive. Good for visual learners who want to see queries built step by step.
Phase 1
freeCodeCamp — Python full course
youtube.com (freeCodeCamp)
4-hour comprehensive Python course. Good refresher for Python foundations. Watch at 1.5x speed.
Phase 2
Real Python
realpython.com
Best free Python articles for DE-specific patterns. Search: Python ETL, SQLAlchemy, pandas, logging, pytest.
Phase 2–3
Databricks Academy
databricks.com/training
Free course covering Python through pandas and cloud computing fundamentals with hands-on labs.
Phase 2
Docker — Get started
docs.docker.com/get-started
Official Docker tutorial. Learn Dockerfile + Docker Compose for running Postgres + Python locally.
Phase 3
dbt Learn — dbt Fundamentals
learn.getdbt.com
dbt Labs' free self-paced course (~5 hours). Covers models, sources, tests, and documentation. Best dbt intro available.
Phase 4
Apache Airflow — official tutorial
airflow.apache.org
Official tutorial for writing your first DAG. Pair with Zoomcamp Week 2 materials.
Phase 4
Google Cloud Skills Boost
cloudskillsboost.google
Free GCP labs. Focus on: BigQuery, Cloud Storage, IAM. Aligns with the Zoomcamp's GCP usage.
Phase 4
DataTalks.Club DE Zoomcamp
github.com/DataTalksClub
Your destination after 8 weeks. Free on GitHub. Covers GCP, Terraform, Airflow, dbt, Spark, Kafka, and capstone project.
