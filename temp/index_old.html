SQLBolt FREE
sqlbolt.com
Fast, interactive SQL lessons. Best starting point — no signup, instant feedback. Lessons 1–12 cover all fundamentals.

CS50 SQL — Harvard FREE
cs50.harvard.edu/sql/2024
Rigorous 7-week SQL course. Covers schema design, indexes, query planning, views, and transactions. The best free SQL course available.
Weeks 1–2
pgexercises.com FREE
pgexercises.com
PostgreSQL-specific drills from basic to advanced. Daily practice engine throughout Phase 1–2. No setup needed.
Weeks 1–3
DataLemur SQL Tutorial FREE
datalemur.com/sql-tutorial
Best free resource for advanced SQL: window functions, CTEs, LEAD/LAG, pivoting. Real interview problems from FAANG companies.
Weeks 2–3
LeetCode — Top SQL 50 FREE TIER
leetcode.com — Top SQL 50
The 50 most important SQL interview problems. Structured study plan. Used weekly throughout this plan for interview prep.

IBM DE Certificate — Coursera AUDIT FREE
coursera.org — IBM Data Engineer
Full DE curriculum: SQL, databases, data warehousing, NoSQL, big data. Audit = watch all content for free. Skip graded assignments.
Weeks 3–4
Real Python FREE
realpython.com
Best free Python articles for DE patterns. Search: Python ETL, SQLAlchemy, pandas, logging, pytest, requests. Precise and practical.
Weeks 4–6
freeCodeCamp Python FREE

github.com/DataTalksClub
Your destination after 8 weeks. Free on GitHub. Covers GCP, Terraform, Airflow, dbt, Spark, Kafka, and a full capstone project. The best free DE bootcamp.
