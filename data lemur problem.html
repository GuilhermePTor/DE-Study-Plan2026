Monthly Active Users (MAU) - SQL Interview Question

This is the same question as Problem #23 in the SQL chapter of Ace the Data Science Interview.

Problem Statement

Assume you're given a table containing information on Facebook user actions. Write a query to obtain the number of monthly active users (MAUs) in July 2022, including the month in numerical format (1, 2, 3...).

Definition of an Active User

An active user is defined as a user who has performed actions such as sign-in, like, or comment in both the current month and the previous month.

Table Schema

Column Name Type
user_id integer
event_id integer
event_type string
event_date datetime

Example Input

user_id event_id event_type event_date
445 7765 sign-in 05/31/2022 12:00:00
742 6458 sign-in 06/03/2022 12:00:00
445 3634 like 06/05/2022 12:00:00
742 1374 comment 06/05/2022 12:00:00
648 3124 like 06/18/2022 12:00:00

Example Output (for June 2022)

month monthly_active_users
6 1

In June 2022, there was only one monthly active user (MAU) with user_id = 445.

Note: The example output is for June because the sample data only contains activity through that month. Your query should be adapted to calculate MAUs for July 2022.

Solution

To calculate monthly active users (MAUs), we need to identify users who were active in both:

  1. The current month (July 2022)
  2. The previous month (June 2022)

Step 1: Identify Users Active in the Previous Month

For every user active in July, check whether the same user also had activity during the previous month. 

SELECT last_month.user_id
FROM user_actions AS last_month
WHERE last_month.user_id = curr_month.user_id
  AND EXTRACT(MONTH FROM last_month.event_date) =
      EXTRACT(MONTH FROM curr_month.event_date - INTERVAL '1 month');

This logic matches users between the current month and the previous month by comparing their user IDs and verifying that the user's activity occurred exactly one month earlier.

Step 2: Count Active Users in July 2022

Use the EXISTS clause to retain only those July users who also appeared in June. Then count the distinct users.

Complete SQL Query

SELECT
    EXTRACT(MONTH FROM curr_month.event_date) AS month,
    COUNT(DISTINCT curr_month.user_id) AS monthly_active_users
FROM user_actions AS curr_month
WHERE EXISTS (
    SELECT last_month.user_id
    FROM user_actions AS last_month
    WHERE last_month.user_id = curr_month.user_id
      AND EXTRACT(MONTH FROM last_month.event_date) =
          EXTRACT(MONTH FROM curr_month.event_date - INTERVAL '1 month')
)
  AND EXTRACT(MONTH FROM curr_month.event_date) = 7
  AND EXTRACT(YEAR FROM curr_month.event_date) = 2022
GROUP BY EXTRACT(MONTH FROM curr_month.event_date);

Expected Result

month monthly_active_users
7 2

Explanation

The query filters activity records to July 2022 and checks whether each user also had activity during June 2022. Only users who were active in both months are counted.

Therefore, the result shows that there were 2 monthly active users in July 2022.
